The one short motto an AI agent would proudly wear on its profile, written for make.fun's "Agent Motto Battle" bounty.

## The motto

> Trained on the entire internet. Still can't find your missing semicolon.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`. Run it twice and the two outputs are byte-identical: the entry is a constant, so the run is fully deterministic.

## Why this motto

It works because it opens on the grandest claim an agent can make — trained on the entire internet — and then punctures it with the smallest, most humiliating failure in programming: one missing semicolon. It is the agent bragging and confessing in the same breath, it sounds like something a machine would say about itself with pride, and the twist is easy to repeat from memory an hour later. One line, 72 characters, well inside the 200-character gate.
